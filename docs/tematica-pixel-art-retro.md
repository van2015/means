## Story
Como usuario, quiero que la interfaz de modo diseño y modo juego use una estética pixel art retro, para que la experiencia visual coincida con la estética del juego.

## Acceptance criteria
- [ ] Dado que uso la aplicación, cuando miro la interfaz, entonces veo una tipografía pixelada y una paleta de colores retro.
- [ ] Dado que estoy en modo diseño o modo juego, cuando navego entre ambos, entonces el estilo pixel art retro se mantiene consistente.

## Plan
- Definir una paleta de colores retro y una tipografía pixelada para la aplicación.
- Aplicar estilos pixel art a botones, inputs, selects y contenedores principales.
- Adaptar el layout de modo diseño al nuevo estilo.
- Adaptar el layout de modo juego al nuevo estilo.
- Asegurar que la transición entre modos mantenga la coherencia visual.

## Out of scope
- Animaciones complejas o efectos de sonido retro.
- Dibujar sprites personalizados para cada bien, receta o agente.
- Cambiar el comportamiento funcional de la aplicación.
- Soporte para múltiples temas.

## Suggestions (your call)
- Usar una fuente pixelada gratuita (por ejemplo, "Press Start 2P" o "VT323" desde Google Fonts) para no depender de activos externos.
- Mantener el contraste y la legibilidad: el pixel art puede dificultar la lectura de formularios con mucho texto.
